# Vexa AI — Global Bilingual Voice & Intelligence Assistant

**Vexa AI** is a next-generation bilingual (English & Persian) AI voice and action assistant for Android.

## Key Capabilities
- **Bilingual Voice & Chat (Auto-Detect EN / FA)**: Speak or type naturally in English or Persian; Vexa AI detects the language automatically and replies in the same language with native voice synthesis.
- **No VPN / No API Key Setup Required**: Pre-configured with your Cloudflare Worker edge gateway (`https://wolf-ai.amirmahdi-akhgari1390.workers.dev`).
- **AI Image Generation**: Generate high-resolution artwork from text prompts and save directly to Gallery.
- **Real File Creation**: Generate and share real `.pdf`, `.py`, `.csv`, `.html`, `.kt`, `.js`, `.json`, `.md`, and `.txt` files on device.
- **Live Trading & Chart Analysis**: Real-time market prices, RSI-14 technical indicator, position size & leverage risk calculator, and chart image analysis.
- **Full Android Device Control**: Calls, SMS, WhatsApp messages, Google Maps navigation, YouTube playback, flashlight, volume, alarms, timers, clipboard, and persistent long-term memory.
